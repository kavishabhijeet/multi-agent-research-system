# Multi-Agent Research System

## 🚀 Overview
This project is a multi-agent research system using LangChain, Mistral, and Tavily.

## ⚙️ Features
- Web search using Tavily
- Web scraping using BeautifulSoup
- ReAct agent reasoning
- LCEL pipeline (no chains)

## 🛠️ Tech Stack
- Python
- LangChain
- Mistral API
- Tavily API

## ▶️ How to Run
```bash
pip install -r requirements.txt
python main.py
